# DCITエキスパート京橋オフィス ポータルアプリ (フロントエンド)

本リポジトリは、業務効率化および就労移行支援の訓練を目的として開発されたシングルページアプリケーション（SPA）のフロントエンドソースコードです。
ユーザーフレンドリーなUIと、保守性の高いコード設計を意識して構築しています。

## 🛠 技術スタック
- **言語・フレームワーク**: React (TypeScript) + Vite
- **スタイリング**: Tailwind CSS (レスポンシブデザイン・ダークモード対応)
- **ルーティング**: React Router (HashRouterを利用し、静的ホスティングに最適化)

## ✨ 主なアピールポイント（設計上の工夫）
- **コンポーネント指向の設計**: 各機能（ポモドーロタイマー、AIプロンプト逆引き辞典、フィードバック送信など）を独立した機能単位で分割し、再利用性と可読性を高めています。
- **カスタムフックによるロジックの共通化**: API通信ロジックを `useApi` フックとして抽象化し、ローディング状態やエラーハンドリングを全画面で一貫して処理できるようにしています。これによりコンポーネント内の記述をシンプルに保っています。
- **モダンな開発・デプロイ環境**: Viteによる高速なビルド環境と、TypeScriptによる型安全な開発を実現しています。また、npmスクリプトによる GitHub Pages への自動デプロイ環境を整えています。

## 🚀 環境構築と起動

初めて開発環境を構築する際の手順です。

1. **パッケージのインストール**
   ```bash
   npm install
   ```
2. **ローカルサーバーの起動**
   ```bash
   npm run dev
   ```
   ※ターミナルに表示されるURL（例: `http://localhost:5173/`）をブラウザで開いて確認できます。

## 📦 ビルドとデプロイ
- **本番用ビルド**: `npm run build`
- **GitHub Pages への公開**: `npm run deploy` (ビルド結果である `dist` フォルダを自動でアップロードします)

## 📁 主要なフォルダ構成
- `src/pages/`: 各アプリケーションや画面ごとのコンポーネント。
- `src/hooks/`: アプリ全体で再利用するカスタムフック (`useApi.ts` など)。
- `src/utils/`: 共通のユーティリティ関数。
- `src/types/`: TypeScriptの型定義ファイル。
