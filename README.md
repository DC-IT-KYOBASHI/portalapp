# 🌟 DCITエキスパート京橋オフィス アプリ集

このプロジェクトは、就労移行支援の訓練や業務効率化に役立つ「便利アプリ」を集めたポータルサイトです。
チームメンバー全員で協力して、新しいアプリをどんどん追加していきましょう！

---

## 🚀 1. 開発の始め方 (セットアップ手順)

初めてこのプロジェクトを自分のPCで触る際の手順です。

1. **VSCodeでこのフォルダを開く**
   * 右下に「推奨拡張機能をインストールしますか？」という通知が出たら、必ず**「インストール」**をクリックしてください。（これにより、コードを保存した時に自動で綺麗に整頓されるようになります！）
2. **必要なパッケージをインストールする**
   * VSCodeの上のメニューから `ターミナル` ➡ `新しいターミナル` を開きます。
   * 下の画面（ターミナル）に以下のコマンドを入力して `Enter` を押します。
     ```bash
     npm install
     ```
   * *※これは、このアプリを動かすための「部品」をインターネットからダウンロードする作業です。最初の一回だけ行います。*
3. **ローカルサーバーを起動する（開発スタート！）**
   * 続いて以下のコマンドを入力して `Enter` を押します。
     ```bash
     npm run dev
     ```
   * 画面に `http://localhost:5173/` のような文字が出たら、そのURLを `Ctrl` を押しながらクリック（またはブラウザに入力）してください。自分のPC上でアプリが動いているのが確認できます！

---

## 📂 2. フォルダの構成 (どこに何があるか)

アプリのコードは主に `src` (ソース) フォルダの中にあります。

* `src/pages/` ➡ 各画面のプログラムが入っています。
  * `PortalHome/` ➡ トップページ（アプリ一覧画面）
  * `PomodoroTimer/` ➡ ポモドーロタイマー
  * `PromptDictionary/` ➡ AIプロンプト逆引き辞典
  * `FeedbackForm/` ➡ 不具合・要望フォーム
  * `Changelog/` ➡ 更新履歴
* `src/utils/api.ts` ➡ バックエンド(system-admin)と安全に通信するための共通API関数(`fetchApi`)が入っています。
* `src/App.tsx` ➡ ヘッダー（タイトルや月のマーク）と、画面切り替え（ルーティング）の設定を行うファイルです。
* `src/index.css` ➡ 全体のデザイン（背景色や文字色）を設定するファイルです。

## 🛠️ 3. 新しいアプリを追加する手順（超入門）

新しく「メモ帳」や「日報作成」などのアプリを追加して、トップページから移動できるようにする手順です！

### ステップ1: 新しいアプリのフォルダを作る
1. `src/pages/` の中に、新しいフォルダを作ります。例：`src/pages/MemoApp/`
2. そのフォルダの中に `index.tsx` というファイルを作って、画面の中身（Reactコンポーネント）を書きます。
   ```tsx
   // 例: src/pages/MemoApp/index.tsx
   export default function MemoApp() {
     return (
       <div className="glass-panel p-8 rounded-3xl text-center">
         <h2 className="text-2xl font-bold">メモアプリ</h2>
         <p>ここにメモ帳の機能を書いていきます！</p>
       </div>
     )
   }
   ```

### ステップ2: トップページにリンク（カード）を追加する
1. `src/pages/PortalHome/index.tsx` を開きます。
2. 上の方にある `const apps = [...]` のリストの中に、新しいアプリの情報を追記します。
   ```tsx
   const apps = [
     {
       title: 'ポモドーロタイマー',
       description: '...',
       // ... 省略 ...
     },
     // 👇 ここに新しく追加！
     {
       title: 'メモアプリ',
       description: 'ちょっとしたアイデアを書き留めるメモ帳です。',
       icon: '📝',
       path: '/memo', // 👈 アドレスバーに表示される名前
       color: 'bg-yellow-500/10 text-yellow-600 dark:text-yellow-400 border-yellow-500/20'
     }
   ]
   ```

### ステップ3: アプリのURL（ルート）を登録する
1. `src/App.tsx` を開きます。
2. 一番上で、さっき作ったアプリをインポート（読み込み）します。
   ```tsx
   import PortalHome from './pages/PortalHome'
   import PomodoroTimer from './pages/PomodoroTimer'
   import MemoApp from './pages/MemoApp' // 👈 これを追加
   ```
3. 下の方にある `<Routes>` の中に、`<Route>` を一行追加します。
   ```tsx
   <Routes>
     <Route path="/" element={<PortalHome />} />
     <Route path="/pomodoro" element={<PomodoroTimer />} />
     <Route path="/memo" element={<MemoApp />} /> {/* 👈 これを追加 */}
   </Routes>
   ```

**これで完了です！🎉**
トップページに新しいカードが表示され、クリックすると「メモアプリ」の画面に切り替わります！

## 🧹 4. 開発のお約束 (ルール)

* **コードを保存 (Ctrl + S) すると自動で綺麗になります！**
  * 変なスペースが空いてしまったりしても、保存時に「Prettier」というツールが自動で修正してくれます。気にせずどんどん書きましょう。
* **手動で全体を綺麗にしたい時**
  * ターミナルで `npm run format` と打ち込むと、全てのファイルが一気に綺麗に整います。

## 🌍 5. サイトの公開 (GitHub Actions への自動デプロイ)

本プロジェクトは **GitHub Actions による自動化（CI/CD）** が設定されています。
そのため、手動でビルド（`npm run build`）やデプロイ用のコマンドを打つ必要はありません。

### ⚠️ 【重要】本番反映（mainブランチ）の厳守ルールとデプロイ手順

いきなり本番用（`main`）のコードを書き換えるのはバグの原因になるため**厳禁**です。以下のフローで開発と自動デプロイを行ってください。

1. **作業用ブランチの作成**: 
   開発を始める際は、必ず `main` ブランチから作業用のブランチを切って作業します。
   ```bash
   git checkout -b feature/新しい機能名
   ```
2. **ローカルでの動作確認**:
   作業が完了したら `npm run dev` でローカルサーバーを立ち上げ、**「新機能が正しく動くか」「既存の機能が壊れていないか」**をブラウザで必ずテストします。
3. **mainへの統合（マージ）と自動デプロイ**:
   テストに合格した場合のみ、`main` ブランチへ戻って変更を取り込み、GitHubへプッシュします。
   ```bash
   git checkout main
   git merge feature/新しい機能名
   git push origin main
   ```
   🎉 **これだけで完了です！** 
   `main` ブランチに変更がプッシュされると、GitHub Actions が自動的にコードをビルドし、数分後に設定したURLへ本番公開（デプロイ）されます。

## ⚙️ 6. バックエンド（管理画面・データ管理）について

このポータルは、各種アプリのデータ（プロンプト辞書など）や、不具合一覧などを管理するために **バックエンド管理画面 (system-admin)** が用意されています。

新しいアプリを追加して、そのデータを管理する画面も必要になった場合は、`system-admin` フォルダ内に管理画面を追加します。
バックエンドへの追加方法や編集方法については、`system-admin/README.md` を確認してください！

## 🧩 7. システム設定ファイル（設計図）の解説

フロントエンド開発では、ソースコード（`src/`）以外にも様々な「設定ファイル」や「隠しフォルダ（`.`から始まるもの）」が存在します。これらはシステムを安全に構築・稼働させるための**設計図やルールブック**として機能しています。学習の参考にしてください。

*   **`.vscode/` フォルダ（エディタの共有設定）**
    *   開発に使うエディタ（VSCode）の設定ファイルが入っています。「コードを保存した時に自動で綺麗にする（Prettier）」などのルールをチーム全員で強制・共有するための仕組みです。
*   **`.github/` フォルダ（自動化ワークフロー）**
    *   GitHub Actions（自動化システム）の設定ファイル（ワークフロー）が入っています。「コードがアップロードされたら、自動でGitHub Pagesへデプロイ（公開）する」といった手順書が書かれています。
*   **`package.json`（プロジェクトの履歴書・設計図）**
    *   ReactやTailwindなど、このアプリが動くために「どのパッケージが必要か」がリスト化されています。また、`npm run dev` などの便利なコマンド（スクリプト）もここに定義されています。
*   **`package-lock.json`（バージョンの完全固定版）**
    *   `package.json` よりさらに細かく、「どのパッケージの『どのバージョン』をインストールしたか」を正確に記録しています。これがあることで、別のPCでも全く同じ開発環境を安全に再現できます。
*   **`vite.config.ts`（Viteのセッティング書）**
    *   超高速なビルドツール「Vite」の設定ファイルです。Reactを動かすためのプラグイン設定や、本番公開用ファイル（ビルド）をどう作成するかを制御します。
*   **`tailwind.config.js`（デザインのカスタマイズ表）**
    *   Tailwind CSSの設定ファイルです。標準にはないオリジナルの色（ブランドカラー）を追加したり、どのファイルのクラス名を読み取るかを指定します。
*   **`tsconfig.json` 関連（TypeScriptのルールブック）**
    *   TypeScriptのコンパイラ（翻訳機）に対する設定です。「どれくらい厳密に型をチェックするか」や、Reactのコードをどう解釈するかなどのルールが書かれています。
